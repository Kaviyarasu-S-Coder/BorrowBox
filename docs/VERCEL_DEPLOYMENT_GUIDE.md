# 🚀 Vercel Deployment Guide for BorrowBox

This guide explains how to deploy the **BorrowBox** frontend to [Vercel](https://vercel.com/) and connect it with your backend.

---

## ⚡ Method 1: Deploy via Vercel Dashboard (Recommended)

### Step 1: Import Your GitHub Repository
1. Log into your account on [Vercel](https://vercel.com/).
2. Click **"Add New..."** ➔ **"Project"**.
3. Select your repository: **`Kaviyarasu-S-Coder/BorrowBox`** and click **Import**.

### Step 2: Configure Project Settings
In the Vercel project configuration screen:
- **Framework Preset**: `Vite`
- **Root Directory**: `frontend` *(Click Edit and choose `frontend`)*
- **Build Command**: `npm run build` *(Auto-detected)*
- **Output Directory**: `dist` *(Auto-detected)*

### Step 3: Set Environment Variables
Under the **Environment Variables** section, add:
| Key | Value | Description |
| :--- | :--- | :--- |
| `VITE_API_URL` | `https://your-backend-domain.com/api` | URL of your live Spring Boot backend |

*(If you are running the backend locally for testing, you can temporarily set `http://localhost:8080/api`).*

### Step 4: Click Deploy
Click **Deploy**. Vercel will build and assign you a live HTTPS URL (e.g., `https://borrowbox.vercel.app`).

## 💻 Method 2: Deploy via Vercel CLI

You can also deploy directly from your local terminal using the official Vercel CLI:

```bash
# 1. Install Vercel CLI globally
npm install -g vercel

# 2. Navigate to frontend directory
cd frontend

# 3. Deploy to preview
vercel

# 4. Deploy to production
vercel --prod
```

When prompted:
- **Set up and deploy?**: `yes`
- **Which scope?**: Choose your personal/team account
- **Link to existing project?**: `no`
- **What's your project's name?**: `borrowbox`
- **In which directory is your code located?**: `./`

## 🌐 Hosting Your Spring Boot Backend

Because Spring Boot 3 is a long-running Java process, host the backend on a cloud container or PaaS provider such as:

### Option A: Render (Free / Easy)
1. Sign up on [Render.com](https://render.com/).
2. Create a **New Web Service** ➔ Connect `BorrowBox` repo.
3. Choose **Docker** as environment.
4. Set **Docker Context**: `./backend`
5. Set **Dockerfile Path**: `./backend/Dockerfile`
6. Add environment variables for PostgreSQL and JWT.
7. Copy your backend live URL (e.g., `https://borrowbox-api.onrender.com`) and set it as `VITE_API_URL` on Vercel.

### Option B: Railway
1. Sign up on [Railway.app](https://railway.app/).
2. Add PostgreSQL and Redis plugins with 1 click.
3. Deploy the backend repository pointing to `backend/Dockerfile`.
4. Copy the public domain generated by Railway and paste into Vercel's `VITE_API_URL`.

## 🔍 Verification & SPA Routing

The included `vercel.json` contains:
```json
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```
This ensures that deep links like `/explore`, `/item/1`, `/profile`, `/borrows`, and `/admin` reload properly without 404 errors.
